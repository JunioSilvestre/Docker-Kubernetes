# 07-laboratorios — Laboratórios Práticos e Ambientes Locais

Clusters locais efêmeros para desenvolvimento e validação de workloads.

## 📂 Subáreas
- [`k3s-kind-homelab/`](./k3s-kind-homelab) — **Stack:** `KinD (Kubernetes in Docker), k3s, minikube` — Subida rápida de clusters leves para desenvolvimento local.
- [`ingress-cert-manager/`](./ingress-cert-manager) — **Stack:** `NGINX Ingress Controller + Cert-Manager` — Emissão automática de certificados TLS gratuitos com Let's Encrypt.
- [`service-mesh-istio/`](./service-mesh-istio) — **Stack:** `Istio / Linkerd conceitos básicos` — Mtls, observabilidade de rede e divisão de tráfego (Canary).

## 📌 Guia de Execução & Padrões
- Todas as implementações desta pasta seguem os padrões de produção estabelecidos para Docker-Kubernetes.
- Consulte os READMEs de cada subárea para detalhes sobre ferramentas e boas práticas.
