# versionamento

> Evitando a tag mutable 'latest' em ambientes de produção.

## 🛠️ Tecnologias & Componentes
- `Tags semânticas (v1.0.0), sha256 digest immutability`

## 📋 Boas Práticas e Padrões de Produção
- Mantenha configurações desacopladas e declarativas.
- Nunca versione senhas, chaves privadas ou tokens em texto puro.
- Siga as diretrizes de padronização corporativa do módulo [`05-registry`](../).
