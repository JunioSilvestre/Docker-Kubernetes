# rollback

> Reversão imediata para a versão funcional anterior em caso de erro no deploy.

## 🛠️ Tecnologias & Componentes
- `kubectl rollout undo, histórico de revisões`

## 📋 Boas Práticas e Padrões de Produção
- Mantenha configurações desacopladas e declarativas.
- Nunca versione senhas, chaves privadas ou tokens em texto puro.
- Siga as diretrizes de padronização corporativa do módulo [`04-deployments`](../).
